# P2 阶段审查摘要 — 核心游戏

## 阶段目标
实现五个核心训练游戏：舒尔特方格（含截图难度阶梯）、动态目标追踪、反应射击、抗干扰识别、节奏分离。

## 已完成工作

### 1. 舒尔特方格（`lib/ui/games/schulte/`）
- 完整难度阶梯（对应截图要求）：
  | 等级 | 规格 | 模式 | 限时 |
  |------|------|------|------|
  | L1 | 3×3 | 升序 | 无 |
  | L2 | 4×4 | 升序 | 无 |
  | L3 | 5×5 | 升序 | 无 |
  | L4 | 5×5 | 降序 | 2s/格 |
  | L5 | 5×5 | 首尾交替 | 1.5s/格 |
  | L6 | 6×6 | 首尾交替 | 1s/格 |
- 记录指标：完成时间、错误点击、准确率、中位盘时
- 限时格子有倒计时进度条，超时自动计错并刷新

### 2. 动态目标追踪（`lib/ui/games/tracking/`）
- 移动靶在屏幕内随机移动，边界反弹
- 6 级难度：目标大小递减、速度递增、目标数量 1→3
- 记录指标：命中次数、脱靶次数、准确率、平均反应时
- 30 秒一局，动画用 AnimationController 驱动

### 3. 反应射击（`lib/ui/games/shooting/`）
- 目标随机出现、限时停留，命中即刷新
- 6 级难度：目标缩小、停留缩短、总数递增
- 记录指标：命中、脱靶、最高连击、准确率、平均反应时
- 目标红橙色光晕，贴合射击主题

### 4. 抗干扰识别（`lib/ui/games/interference/`）
- Stroop 变体：显示彩色汉字，用户选颜色不读字
- 6 级难度：一致试次占比 70%→20%、反应时限 2000ms→1000ms
- 记录指标：准确率、正确反应中位数、不一致冲突耗时
- 30 题一局，每题反馈「正确/错误/超时」

### 5. 节奏分离（`lib/ui/games/rhythm/`）
- 左右两个区域按不同节奏闪烁，用户分别计数
- 6 级难度：左右节拍比从 1:1 到 4:3，容差递减
- 记录指标：准确率、节拍误差中位数
- 20 题一局；当前为视觉闪烁版，音频节拍待 P5 接入 audioplayers

### 6. 整合与路由
- 训练大厅从 6 入口扩展为 8 入口
- 新增路由：`/training/interference`、`/training/rhythm`
- 常量新增 `interference`、`rhythm` 模块类型
