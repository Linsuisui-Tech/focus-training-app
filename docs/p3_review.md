# P3 阶段审查摘要 — 内容与计划

## 阶段目标
实现 10 套预置训练计划、饮食与健康指导文本、程序化视频库。

## 已完成工作

### 1. 数据模型（`lib/data/models/training_plan.dart`）
- `PlanModule`：计划中的一个训练模块（类型、标题、时长、难度、重复次数、参数）
- `TrainingPlan`：完整计划（id、名称、描述、强度、场景、模块列表）
- 支持 JSON 序列化，为 P4 本地存储预留

### 2. 10 套预置训练计划（`lib/data/presets/preset_plans.dart`）
| 档位 | 计划 | 时长 | 模块组合 |
|------|------|------|----------|
| 低 | 晨间唤醒 | 5min | 舒尔特3×3 + 呼吸唤醒 |
| 低 | 通勤专注 | 5min | 听觉专注 + 反应射击20次 |
| 低 | 睡前舒缓 | 5min | 呼吸放松 + 助眠声景 |
| 中 | 午休重启 | 15min | 舒尔特4×4 + 动态追踪 + 冥想 |
| 中 | 视觉强化 | 15min | 舒尔特5×5 + 追踪 + 快速定位 |
| 中 | 深度工作预备 | 15min | 反应射击 + 声景 + 番茄钟 |
| 中 | 认知抑制 | 15min | 抗干扰识别 + 听觉专注 |
| 高 | 射击专项 | 30min | 快速定位 + 追踪 + 射击进阶 |
| 高 | 全脑激活 | 30min | 舒尔特6×6 + 追踪 + 射击 + 抗干扰 |
| 高 | 动态反应 | 30min | 高速追踪 + 极限射击 |

### 3. 训练计划系统界面（`lib/ui/plans/`）
- `plans_screen.dart`：Tab 切换「推荐方案 / 我的计划」；推荐方案按强度分三组展示，卡片含强度徽章、时长、模块数、场景
- `plan_detail_screen.dart`：展示计划详情、模块清单（带序号、时长、难度）、底部「开始训练」按钮（跳转第一个模块）
- 自定义计划入口已预留，编辑器待 P4 接入本地存储

### 4. 饮食与健康指导（`lib/data/presets/diet_content.dart` + `lib/ui/diet/diet_screen.dart`）
- 5 大分类：专注力友好食物、睡眠与恢复、用眼与护眼、运动与大脑、生活习惯
- 共 16 篇通俗文章，每篇含生活化类比（如 Omega-3=润滑油、BDNF=肥料、血糖=油）
- 三级导航：分类 → 文章列表 → 文章详情

### 5. 程序化视频库（`lib/ui/video/video_library_screen.dart`）
- 4 种程序化专注动画，无外部视频文件依赖：
  - 呼吸圆环（正弦缩放，模拟吸气呼气）
  - 节拍器（周期闪烁）
  - 粒子漂流（椭圆轨道随机粒子）
  - 光轨扩散（三层涟漪）
- 播放页支持播放/暂停、0.5x-2.0x 速度调节

## 关键决策与说明

| 决策 | 说明 |
|------|------|
| 数据用 Dart 常量而非 JSON 文件 | 预置计划/饮食内容用 `const` 常量定义，类型安全、无需资源加载；后续可迁 JSON |
| 计划数据暂不持久化 | P4 阶段接入 Hive 本地存储，实现自定义计划的保存 |
| 视频库用 CustomPainter 动画 | 程序化生成，避免版权和网络依赖，符合 P1 确认方向 |
